Index over the Ptolemy II actor catalog, used by {@link org.ptolemy.agent.tools.ListLibraryTool} to give the LLM (and the frontend library panel) a stable list of class names plus short descriptions to choose from.

M2 ships with a small curated set covering the actors needed for the canonical RC-low-pass and PID-tuning demos. M5 expands it to the full {@code ptolemy/configs/basicLibrary.xml} catalog.

@since Ptolemy II 11.1
