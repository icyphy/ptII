HTTP entry point for the Ptolemy II auto-modeling agent. Built on the JDK's {@code com.sun.net.httpserver.HttpServer}, so no third-party HTTP dependencies are required to compile or run.

The server exposes a small REST API under {@code /api/v1/}; see {@link org.ptolemy.agent.server.RestRoutes} for the route table.

@since Ptolemy II 11.1
