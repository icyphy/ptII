Pluggable "tools" the agent (or a human user) can invoke to mutate a Ptolemy II model and to inspect it.

The {@link org.ptolemy.agent.tools.AgentTool} interface is the unit of pluggability. Every tool advertises a JSON Schema that the LLM consumes through OpenAI-style function calling, and executes by emitting a {@link ptolemy.moml.MoMLChangeRequest} against the target session.

Tools available in M2:

  • {@code add_entity} — instantiate any actor inside the top-level composite
  • {@code connect} — connect two ports through a new {@code TypedIORelation}
  • {@code set_parameter} — set a parameter value on an existing entity
  • {@code delete} — remove an entity
  • {@code run} — run the simulation to completion
  • {@code list_library} — list curated actor classes for the LLM
  • {@code validate} — parse-validate a MoML fragment without applying it

The same registry is consumed by the LLM agent loop and by the frontend canvas (M3+), so manual edits and automated edits go through the exact same code path.

@since Ptolemy II 11.1
