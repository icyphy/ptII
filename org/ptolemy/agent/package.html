The org.ptolemy.agent package.

This package adds an "automatic modeling agent" capability on top of Ptolemy II. It embeds the Ptolemy II kernel (MoMLParser, Manager, CompositeEntity, etc.) into a long-running REST/WebSocket service so that a Large Language Model (LLM) can drive model construction through a small set of tool functions, and so that a decoupled web frontend can render the model and plot simulation results.

The Ptolemy II kernel itself is NOT modified. All integration goes through existing public APIs:

  • {@link ptolemy.moml.MoMLParser} for parsing initial models or fragments produced by tools.
  • {@link ptolemy.moml.MoMLChangeRequest} for incremental edits (add entity, connect, set parameter, delete).
  • {@link ptolemy.actor.Manager} for running simulations and reporting state via {@link ptolemy.actor.ExecutionListener}.
  • {@link ptolemy.actor.lib.Recorder} actors are injected automatically to collect output signals.

Sub-packages:

  • session — {@code PtolemySession}, {@code SessionManager}, {@code SignalCollector}, {@code GraphSerializer}.
  • server — {@code AgentServerMain}, {@code SimpleHttpServer}, and the REST/WS route handlers.
  • tools — pluggable {@code AgentTool} implementations (add_entity, connect, set_parameter, run, ...).
  • llm — {@code LLMClient} abstraction plus an OpenAI-compatible implementation.
  • agent — the ReAct-style {@code AgentLoop} that wires tools and LLM together.
  • library — {@code LibraryIndex} that exposes the available actor catalog (from {@code ptolemy/configs/basicLibrary.xml}) to the LLM and the frontend.

@since Ptolemy II 11.1
